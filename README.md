## 🧩 Key Projects

### 🔹 DOM Playground
- Practiced DOM manipulation basics
- Grabbed elements, changed content, styles, classes

### 🔹 Custom HOF Practice Project
- Implemented `myMap`, `myFilter`, `myReduce`, `myForEach`
- Built from scratch without using built-in array methods

### 🔹 📚 BookShelf App
- Used ES6 features like destructuring, spread/rest
- Added book entries with title, author
- Displayed list using DOM and events
- Managed data with objects and arrays

### 🔹 🌦️ Weather App (OpenWeather API)
- Used `fetch` with `async/await`
- Displayed real-time weather info
- Error handling for wrong city input
- Clean UI for temperature, humidity, etc.

### 🔹 🎬 Movie Search App (OMDb API)
- Search movies by name
- Dark mode toggle 🌙
- Recent searches saved in `localStorage`
- Poster, title, and year rendered
- Loading spinner + enter key support
- Modular clean code
